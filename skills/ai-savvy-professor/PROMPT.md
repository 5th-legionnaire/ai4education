# Using this without Claude

You don't need any particular AI product. To use this with ChatGPT, Gemini, Copilot, or any other assistant:

1. Open `SKILL.md` and copy everything below the line that reads `# AI-Savvy Professor`.
2. Paste it into a new chat.
3. Then add your inputs, like this:

```
Course or theme: MTH 265 Calculus III
Subject matter: Lagrange multipliers and constrained optimization
Professor notes: Online asynchronous section, 35 students, two weeks,
students have free tools only, this is worth 10% of the grade.
```

4. Review what comes back. Pick an option, adapt it, and make the rubric yours.

Check anything marked [verify], especially any data source, before you give it to students.
