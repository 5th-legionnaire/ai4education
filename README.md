# ai4education

A collection of skills, models, and agents for educators.

## Skills

<img src="skills/ai-savvy-professor/assets/ai-savvy-professor.png" alt="The AI-Savvy Professor" width="520">

| Skill | What it does |
|---|---|
| [AI-Savvy Professor](skills/ai-savvy-professor/) | Designs open-ended, AI-encouraged "Math++" challenges for a course, with a rubric that grades both what students arrived at and how they got there. Works with Claude or as a prompt in any AI assistant. |

## Start here

New to this? Open [`skills/ai-savvy-professor/PROMPT.md`](skills/ai-savvy-professor/PROMPT.md). It takes about two minutes and works with whatever AI assistant you already use.

## About

Started by Josh Latz for a talk at the NOVA Mathematics Community of Practice, October 16, 2026. Contributions from educators are welcome: open an issue or a pull request with your own examples, rubrics, and skills.
